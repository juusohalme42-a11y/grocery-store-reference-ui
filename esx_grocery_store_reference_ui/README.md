# Grocery Store Reference UI

A grocery store UI inspired by the reference image, with:
- left-side inventory preview
- right-side shop item list
- name, money, and inventory usage display
- ox_inventory-style bottom action buttons

## Installation
1. Put this folder into your `resources` directory.
2. Add to `server.cfg`:
   ```cfg
   ensure es_extended
   ensure ox_inventory
   ensure esx_grocery_store_reference_ui
   ```
3. Restart the server.

## Notes
This is a UI-focused reference resource that mirrors the layout of the provided screenshot while remaining easy to customize.
